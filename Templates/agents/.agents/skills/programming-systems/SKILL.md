# Scope

- This skill always applies to compiled, strongly typed, non-gc'd languages including but not limited to C, C++, Rust, Zig, Odin, and Jai.

# Code Construction

- If the language supports assertions that can be discarded at compile time, use them liberally.

# Data Structures

- Prefer using structs of arrays rather than arrays of structs
